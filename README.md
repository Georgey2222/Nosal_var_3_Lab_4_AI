# Лабораторна роюота 4

Реалізація гри "Життя" Конвея на основі ООП

Задачу розподілено між трьома класами:

Board - зберігає поле, генерує наступне покоління, виконує дії над полем;
Game - логіка гри, зберігає історію, виконує дії step та back, відповідає за оновлення поля;
CommandProcessor - відповідає за команди, введені користувачем;

Програма є консольною, тобто запускається в терміналі, однак має досить потіжний функціонал.

Дозволяє задавати початкову конфугурацію самостійно, а також генерувати рандомно.

Також є можливість відмотувати попередні дії назад та змінювати розмір поля.
